# Credits

Tauri Starter builds on the work of the open-source community.

## Core stack

- [Tauri](https://tauri.app) — Rust-based cross-platform desktop runtime
- [React](https://react.dev) — frontend UI library
- [Vite](https://vitejs.dev) — build tooling
- [TypeScript](https://www.typescriptlang.org) — type system
- [Tailwind CSS](https://tailwindcss.com) + [shadcn/ui](https://ui.shadcn.com) — styling and components
- [specta / tauri-specta](https://github.com/specta-rs/tauri-specta) — compiler-derived TypeScript bindings for Rust commands
- [Zod](https://zod.dev) — runtime schema validation for settings and backups
- [Zustand](https://github.com/pmndrs/zustand) — frontend state
- [keyring](https://crates.io/crates/keyring) — OS keychain access for secure storage
- [i18next](https://www.i18next.com) / [react-i18next](https://react.i18next.com) — localization
- [Lucide](https://lucide.dev) — icon set
- [Vitest](https://vitest.dev) + [Testing Library](https://testing-library.com) — tests

Plus the official Tauri v2 plugins: `store`, `deep-link`, `single-instance`,
`window-state`, `dialog`, `fs`, `log`, `notification`, `global-shortcut`,
`autostart`, `os`, and `opener`.

See each project's license for terms.
