# Changelog

All notable changes to Tauri Starter are listed here. This project follows
[Conventional Commits](https://www.conventionalcommits.org); see `git log` for
the full history.

## 1.0.0 — Unreleased

First open-source release.

- Desktop platform: single-instance app intents, `tauri-starter://` deep links,
  system tray, native menu, native notifications, a shortcut registry for
  in-window and global shortcuts with per-user overrides, launch at login, window state and zoom persistence, file
  dialogs with recent files.
- Type-safe IPC: Rust `#[tauri::command]` functions with TypeScript bindings
  generated by `tauri-specta`, and a CI check that fails on binding drift.
- Security: per-plugin capability grants, a CSP with no external origins, an
  external-URL policy limited to `https:` and `mailto:`, log redaction, and
  OS-keychain secure storage.
- App shell: custom titlebar, settings center with search, command palette,
  first-run onboarding with an optional EULA, accent theming, i18n (en/zh),
  About, Logs, Help, and Error pages, and an offline banner.
- Data on the device: versioned settings store with migrations, and settings
  backup export and import.
- Showcase: capability catalog with live demos and a components gallery, all
  removable via `docs/CUSTOMIZE.md`.
